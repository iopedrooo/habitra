# HabitRa Mobile Prototype (Expo)

Protótipo funcional inicial em React Native (Expo) com os fluxos principais solicitados:

1. escolha de idioma na primeira tela;
2. login ou criação de conta;
3. username único no cadastro (simulação local);
4. envio e verificação de código por e-mail (simulação);
5. adicionar amigos;
6. hábitos em grupo + metas privadas;
7. visão de calendário combinada.

## Rodar localmente

```bash
cd mobile
npm install
npm run start
```

Depois, abra no Expo Go (Android/iOS) ou no navegador com `w`.

## Observação

Este é um protótipo de interface/fluxo. Integrações reais (SMTP, banco, calendário do sistema, push notifications) ainda precisam de backend e serviços externos.
